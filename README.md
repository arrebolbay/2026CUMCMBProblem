## 二、这批代码是怎么还原出来的

原稿附录里粘贴了源码，但从 PDF 提取文本时**缩进会抖动**：同一层级实测 4~7 个空格、
层级间距约 5，在 7 处出现两义，按空格数机械还原无法收敛（表现为 `unexpected indent`）。

最终改用 **PDF 文本块的精确 x 坐标** 反推缩进层级：

```
层级 = round((x - x0) / 12.15 pt)      # x0 = -23.19 pt（全局代码列左边界）
```

代码块坐标无抖动，因此 **7 个文件一次性全部通过 `ast.parse`**。还原链路可复核：

- `_还原管道/_extract_tjj.py` —— 按坐标提取
- `_还原管道/_annotate_tjj.py` —— 加学习注释
- `_还原管道/论文全文提取.txt` —— 原始提取文本

## 三、注释约定

- 所有新增注释以 `# 【学习注释】` 开头，共 **33 处**（7 处文件头说明 + 26 处关键函数注释）。
- **原有逻辑一行未改**，只添加注释；缩进与空行按代码块坐标复原。
